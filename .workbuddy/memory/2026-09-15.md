## 结尾演出 end_game() 从未被调用（不进入 preending 阶段）

**现象**：跳过 preending 直接走 end 时，夏洛蒂的角色场景没生成、结尾对话也没触发。

**根因**：`end_game()` 只挂在 `_process` 的 boss 分支（`id == end_special_id`）里，而 `world.tscn`
的 GameMap 没有配 `end_presenting_dialgues`（size=0）→ `end_special_id` 恒为 -1 → 该分支永不进入
→ `end_game()` 一次都没执行。看到「kai 在、夏洛蒂不在」是因为玩家节点本身就是 `kai.tscn` 实例
（`world.tscn` 里 `world_map.player = NodePath("kai")`），不是生成的结尾角色。

**修改（scene/game_map.gd）**：
1. `_process` 里把「最后一段对话播完 → 进结尾」从 boss 分支解耦：
   `dialogue_index == dialgues.size() + end_presenting_dialgues.size() - 1` 时，await timeline_ended
   后调 `end_game()` 并 return；boss 挪窝逻辑留在后面的 `id == end_special_id` 分支。
   无 end 对话序列时该下标退化为最后一段普通对话。
2. preending 判定加 `not end_presenting_dialgues.is_empty()` 前置条件（没有 boss 时不该进 preending）。
3. `end_game()` 里补 `presnting_stage = end`。
4. 注册角色时加 `young_chroltte`（final.dtl 的说话人是童年夏洛蒂，只注册 `charlotte` 挂不上气泡）。
5. `spawn_ending_charactors` 不再 `player.visible = false`，改用 `_hide_player_marker()`
   只隐藏玩家的 CanvasItem 子节点、跳过 Camera2D（Camera2D 是 player 的子节点，连它一起藏有风险）。

**验证方式**（可复用）：临时 `check_ending.tscn` 实例化 world.tscn → 把 `Game.scene_flag`
设成 `(1<<(n-1))-1` 逼 `pick_object()` 选中最后一段 → `apply_dialgue_at(idx, player_cell)` →
每帧 `Dialogic.handle_next_event()` 推进 → 打印逐帧布局/时间线/注册表。
结果：`timeline16.dtl → ending=true(chars=2) → final.dtl @ text_bubble_base`，cam 仍 enabled。

**注意**：`Game.scene_flag` 默认 `0b1111111111111111`（前 16 位已置位），17 段对话下
`pick_object()` 第一次就返回 16（最后一段），所以进游戏走一步就会直接进结尾。
正常从头玩要把它清零。

## voronoi_background 增加 force_background

- @export var force_background:bool = false；为真时 add_point 的 render_target 强制为 BACKGROUND（不受 seted_color 影响），颜色逻辑不变（0 号随机 / 1-6 对应色）。
- 注意 render_target 是逐实体存储的：bool 只影响开启后新生成的点，已存在的点不回溯。
