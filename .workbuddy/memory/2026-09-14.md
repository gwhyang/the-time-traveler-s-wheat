# 2026-09-14

- 修复 game_map.gd preending 阶段触发一次对话后无法移动的 bug：`boss_waiting = true; await Dialogic.timeline_ended` 原来无条件执行，当 `pick_object()` 在 preending 下返回普通对话下标（apply_dialgue_at 必返 -1、boss 留在原地且 timeline 已被释放）时，下一帧再次进入等待但没有对话在播放，timeline_ended 永不触发，boss_waiting 永久卡 true 挡住 `_input`。修复：① boss 等待分支加 `dialogue_started` 门控；② `pick_object()` 在 preending 下只从 `dialgues.size()` 开始扫 end_presenting 区间。
- 修复 preending boss 挪窝失效：触发 end 对话会把 `Game.scene_flag` 置位，当 boss 携带最后一段 end 对话下标（或 end_presenting_dialgues.size()==2 时第一个下标）时，同一帧 `presnting_stage` 翻成 end；恢复代码里 `apply_dialgue_at(pick_object(),...)` 走普通生成路径，boss 不挪窝也不回填 timeline，无法再对话。重构：抽出 `apply_end_special(res,cell)`（不依赖 stage），新增 `relocate_end_special(desti,fallback_index)`（preending 下优先 pick_object 的下一段 end 对话，放完则复用 fallback），`_process` boss 分支与 `after_player_move` delet 路径改用它；触发时用 `dialogue_index` 捕获下标作 fallback。
- 修复 preending 只能刷出前 n-1 段 end 对话的 off-by-one：end 对话下标为 dialgues.size()..dialgues.size()+n-1，而 stage=end 判定误写为 `dialgues.size()-1+n-1`（倒数第二段的 bit），导致倒数第二段触发时就翻入 end，relocate 不再走 pick_object，最后一段永远刷不出。已改为 `dialgues.size()-1+n`。
- 新增流程：最后一段 end 对话触发即进入 end 阶段（bit 判定），对话 `timeline_ended` 后调用现成的 `end_game()` stub（函数体待用户实现），且 boss 不再挪窝。
- 验证脚本编译：`godot --headless --path . --quit-after 3`（`--check-only --script` 不加载 autoload，会误报 `Game` 未找到）。
- 新增 `scripts/voronoi_edge_outline.gdshader`：模仿 `vornoi_line_painting.gd` 的描边，但改用屏幕空间边缘检测（8 方向多环采样 `hint_screen_texture`，比较邻域颜色差）判断边缘，无需多边形数据。已用 Steam 版 Godot 4.7.2 headless（`-s` 临时脚本 load）验证编译通过。
- 初版被用户纠正：要求严格模仿 `glowing_outline.gdshader`——显式 `source_texture` 采样 + 12 圈×8 方向辉光（glow_radius/opacity/falloff）。已重写为同结构版本，仅将 alpha 边缘检测换成颜色差边缘检测；挂在显示同一张纹理的节点上（texel 取 TEXTURE_PIXEL_SIZE）。
